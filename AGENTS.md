# Project Development Rules

- Read existing code before making changes.
- Follow the project's established architecture.
- Use Prettier for formatting where configured.
- Follow ESLint rules where configured.
- Never expose API keys, passwords, or secrets.
- Avoid modifying unrelated files.
- Write tests for important functionality.
- Explain significant changes.
- Review the Git diff before committing.
- Ask before destructive commands or deployments.
